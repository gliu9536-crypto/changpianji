# OHM DISC · 唱片机

一个单页的三维唱片机展示页面。唱片机模型完全由代码程序化生成（没有外部模型文件、没有外部贴图、没有网络请求），
材质按物理量设定，支持鼠标旋转 / 缩放 / 双击复位，并带有一套围绕它的动画与交互。

界面做成一台**档案终端**：页头是机型，右侧是当前档案的正文，底部是控制台。
这台唱片机被拆成六条档案——整机，加上拆解图里的五个零件——读一条零件档案，机身会打开、
该零件留在真实材质上、其余零件退成幽灵，镜头同时切到它自己的机位。规格表里的数字基本来自模型本身。

外观走**磨砂玻璃 + 金属点缀**：烟灰磨砂玻璃底座（清漆 + 细磨砂法线）、拉丝铝转盘、铝制 S 型唱臂、
铜色唱片压镇呼应页面的主色。

## 打开

直接双击 `index.html` 即可（已打包成 `dist/app.js`，`file://` 下可以正常运行）。

## 音乐

唱机上放的那首曲子是**启动时程序生成的一段 lo-fi 氛围旋律**：`src/audio.js` 里的 `genMusic()` 在
浏览器里离线合成约 32 秒的和弦垫 + 五声音阶旋律，编码成 WAV → blob URL，喂给 `<audio>`。
进度条 / 计数器 / 循环 / seek 因此全部照常工作，而**没有任何外部音频文件**、也不发任何网络请求。

播放时叠一层黑胶底噪（`VinylAudio`）：稀疏脉冲过高通 = 沟槽里的灰尘噼啪，低频隆隆 = 转盘轴承，
200 Hz 嗡声 = 直驱马达。这套底噪始终是程序生成的，只在播放时出现。

### 装一张自己的

页头的 **ADD MUSIC**（或按 `O`，或把音频文件直接拖到页面上）选一个本地文件，唱片就换成它。
曲名 / 艺人 / 专辑读的是文件自己的 ID3 标签（`src/tags.js`），没有标签就用文件名。跟着一起变的还有：
两面圆标签上的标题、页头的型号铭牌、中间的曲目条、右下角计数器的总长、浏览器标签页的标题。

换片不是一次硬切：新印刷先画在标签上方那层同形状的副本上，再由一条从左扫到右的写头放出来
（`turntable.js` 的写头 / `main.js` 的标签换曲），唱头同时抬起再落下，配一声机械响；
写头扫完的那一刻整页才一起换成新的一首，所以看不到「文字跳了一下」。

再放一首就是替换上一首；刷新页面回到出厂那一首；REINITIALIZE 也把它放回去。
文件不上传到任何地方，也不会被存进浏览器——它只是被 `<audio>` 指着的一个 blob URL。

### 换掉出厂曲目

`src/audio.js` 的 `genMusic()` 里改和弦与旋律，然后双击 `重建.bat`。曲名会自动写到两面标签上。

## 交互

页面是一台档案终端：这台唱片机被拆成 **六条档案**（整机 + 五个零件），`↓↑` 翻档案，`←→` 换机位，
`回车`（或点「读取」、或再点一次已选中的那一行）读取。**读取是唯一会改变画面的动作**——
浏览只移动游标，镜头不会在你读的时候从底下动起来。

| 操作 | 效果 |
| --- | --- |
| `↓` `↑` / 点列表 | 前后翻档案：整机 / 唱片 / 转盘 / 唱臂 / 唱头 / 底座 |
| `←` `→` | 切换机位：等轴 / 正视 / 俯视 / 细节特写。切到「细节特写」时镜头推得很近，唱片机会伸到右边那一栏底下，所以**「细节特写」就是"面板收起"的机位**：选中它整块面板直接自己整个收起，只留编号与读取按钮，不用点收起；离开这个机位自动展开回来 |
| `回车` / 读取按钮 | 读取当前档案 |
| `I` / ARCHIVE INDEX | 打开总目录：六条档案连规格一起列出，点某条的标题直接读取 |
| `O` / ADD MUSIC | 换一首自己的：选本地音频文件，标签被重新写一遍（见「音乐」）。拖一个音频文件到页面上效果相同 |
| `,` / SETTINGS | 打开设置页（见「设置」） |
| `Esc` | 退一层：总目录开着就关目录，否则合上拆解，否则展开收起的面板 |
| 收起详情 | 折叠右侧正文（只留编号与读取按钮） |
| 拖动 | 旋转（带惯性阻尼；松手 3 秒后缓慢自转） |
| 滚轮 / 双指捏合 | 推拉镜头，推近时面板跟着一起变短，推到接近最近时整个收起，往回拉自动展开 |
| 双击 | 回到默认机位 |
| `空格` | 播放 / 暂停：唱片以 33⅓ 转匀速旋转、唱头落针 / 抬针、计数器 = 歌曲进度（放完自动回起点重放），并叠一层黑胶底噪 |
| 拖 / 点滑轨 | 定位：`←` `→` 微调，`Home` / `End` 到两头。seek 时唱臂沿径向从外圈走到内圈（外圈 = 开头、内圈 = 结尾） |
| `E` / 拆解 | 分层展开唱片 / 唱头 / 唱臂 / 转盘 / 底座，并显示五条引线标注 |
| `F` / 翻面 | 整体翻转 180°，看唱片 B 面（背面圆标签） |
| `M` / 静音 | 只关掉声音，转盘动画继续 |
| 喇叭上滚轮 | 调音量：5% 一档，默认 30% |
| `A` / 巡览 | 自动环绕开关 |
| 右上两格 | 换光环境：暗房 / 影棚。环境光、背景、灯位、后期参数整体过渡 |
| REINITIALIZE | 回到初始状态：整机档案、等轴机位、影棚光环境、停止播放 |

`prefers-reduced-motion` 下整套动画退成「切」：不放片头、不呼吸浮动、镜头换机位直接落位、
拆解与幽灵渐变不插值、面板折叠与随镜头变短、主题切换不做过渡。

### 读取一条零件档案会做什么

三件事同时发生：该零件**留在真实材质**上，其余零件**渐变成**一层暖灰的半透明幽灵；
**引线只留该零件那一条**；**镜头切到该档案自带的机位**。幽灵是渐变过去的，不是切过去的
（`paintGhost`，材质副本每 mesh 一份，不触发 shader 重编译）。

## 界面

页面本身是一件印刷品叠在一张照片上：所有用文字说的东西都印在同一块半透明纸上（`.sheet`），
挂在右侧三分之一处。纸自己带段落差（`margin-left: var(--retract)`），折叠、滚轮推近、
「细节特写」三种收法走同一个数。界面上每个长度都是根字号的倍数，根字号是
`clamp(16px, 1.1111vw, 21px)`——1440 下 16px，2560 下 21px，整版一起长大。

底部控制台 `1fr auto 1fr`，中间的翻页块落在画幅自己的中线上；走带台是两行（上排播放 / 计数 /
四个圆钮，下排整整一行给滑轨）。滑轨是 `<input type="range">`，和设置页那根调子是同一个零件。

底部那排键帽每颗是一个真实按键加它干的事，按键时对应键帽会亮。规格表那行关键字和数值之间是
虚线引带。文字与数字各有一个助手（`swapText` / `setRoll`），所以没有一帧是切过去的——图标换的是字、
折叠箭头是画出来的、滑轨填充是自己的元素，主题切换的 token 过渡用 `@property` 注册。

## URL 状态（便于截图/分享）

```
index.html?v=front&x=1&f=1&t=studio&p=1&r=01&ui=0
```
`v` = iso|front|top|detail，`x=1` 拆解，`f=1` 翻面，`t` = noir|studio，`p=1` 播放，
`r=03` 直接打开该编号的档案，`spin=0` 关掉自动巡览，`ui=0` 隐藏界面，`intro=1` 强制播放片头，
`fps=1` 显示帧率 / 每帧 JS 耗时 / 当前 dpr。

## 结构

```
index.html          页面骨架与文案（页头 / 档案纸 / 底部控制台 / 总目录）
styles.css          版式：一套 token，档案纸、控制台、键帽、总目录
src/main.js         装配：渲染器、光环境、相机、档案与零件聚焦、拆解标注、位置滑轨、主循环
src/turntable.js    唱片机模型（几何 / 材质 / 转盘与唱臂动力学 / 拆解 / 标签写头）
src/textures.js     程序化纹理：圆标签、同心沟槽、拉丝金属、磨砂法线、噪点
src/env.js          程序化环境光（柔光箱 HDR 面板 + PMREM）
src/lights.js       两套五灯位摄影棚布光 + 探针用的灯架几何
src/floor.js        实时地面镜像（自算镜像相机 + 竖向拖影 + 模糊变差）
src/probe.js        反射探针（cubemap → PMREM → 作为机身 envMap）
src/ao.js           屏幕空间环境光遮蔽（全分辨率 / 双尺度 / 双边滤波 / 时间累积）
src/post.js         后期链：AO → Bloom → 色调映射 → 暗角/颗粒/色散
src/controls.js     自写轨道控制器（惯性、视差、捏合、自转）
src/audio.js        WebAudio 黑胶底噪 / 马达嗡声 + 程序生成的出厂旋律（genMusic）
src/tags.js         用户自己装进来的音频文件的 ID3 标签
build.mjs           esbuild 打包
重建.bat            双击即可重新打包
tools/page-shot.mjs 通过 CDP 打开真实页面并截图
tools/_px2rem.mjs   把 styles.css 从 px 换成 rem
tools/_ink.mjs      Node 里跑水墨晕染模拟并输出 PNG（调试用）
```

## 画面

- **1.25× 超采样**：后期链路按 1.25 倍渲染、最后一级缩采样；显存吃紧时自动关掉。
- **镜头感**：全屏 pass 里做了散焦、径向色散、暗角、颗粒，加胶片式分离色调与高光暖色溢出（halation）。
- **环境与光**：PMREM 里塞了 7~9 块 HDR 柔光板，环境贴图每帧极慢自转，高光在壳面缓缓游走。
- 2048 阴影贴图 + 软 PCF、雾一样的双层尘埃。
- **实时地面镜像**：每帧用镜像相机渲染一次场景到 RT，采样时沿屏幕 Y 做高斯拖影（抛光石地板的竖向拉伸反射）。
- **片头**：唱片机一开始停在地板上，然后线性带阻尼地悬浮到位，镜头在 3.4 秒里从更远更低的机位推回默认机位，唱片在上升时还在转。

## 灯光（按摄影棚逻辑布）

`src/lights.js` 里是一套照片级的五灯位：key 主光（45° 偏左、暖色）、fill 副光（反侧、大而弱、偏冷）、
rim 轮廓光（背后窄条）、bounce 桌面白卡反弹、top 顶部补光，另有一盏同方向的平行光专门投影。
`RectAreaLight` 是 three 里唯一像柔光箱的光源，但**不能投影**，所以投影单独交给平行光。

## 设置

页头 **SETTINGS**（或 `,`）打开一张设置页，一行一件事：开场动画、循环播放（`AUTO REPLAY`）、
唱片底噪（`VINYL BED`）、按键提示、地面镜像、暗角（唯一一条滑条）。开关记在
`localStorage`（键 `ohm-disc.prefs`）。**只有设置会跨刷新保留**——音乐是故意不保留的。
